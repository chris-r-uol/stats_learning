The Hypothesis Test Workbench No Excel function runs a hypothesis test from summary statistics. T.TEST and the Analysis ToolPak both need raw data, and several questions give you only n, the mean and the standard deviation. The workbench has one sheet per test, with the formulas already built. Each sheet shows the critical value and the p-value side by side.

When a downloaded workbook opens, click Enable Editing in the yellow bar — Excel opens downloaded files read-only until you do.
