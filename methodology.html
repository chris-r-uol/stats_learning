Three problem-solving methods

A method is a set of steps that works for a whole group of problems. Learning these three is more useful than memorising single answers.

1. Evaluating probability intervals

Useful from Tutorial 2 onwards.

  1. Identify the information in the question. Write down the values you are given. Not every detail is needed.
  2. Identify the probability function. A continuous measurement suggests the normal distribution. A fixed number of yes/no trials suggests the binomial. Counts of events in a fixed period suggest the Poisson.
  3. Identify the interval to calculate. Write it out: P(X < 15), P(X > 10), P(a < X < b). Sketch it.
  4. Rewrite it to match your tool. Excel measures area from the left. Any other area must be rewritten as a left-hand area first. This step causes the most difficulty.
  5. Comment on the result. Explain it in plain language. If you cannot explain it to someone without statistics training, you have not finished.
Rules to memorise

P(X > c) = 1 − P(X ≤ c)

P(a < X < b) = P(X < b) − P(X < a)

For discrete data, mind the boundary: P(X < 10) = P(X ≤ 9), which is not the same as P(X ≤ 10).

Worked example

A normal distribution has mean 0 and standard deviation 1. What is the probability that a value drawn from it is less than −2?

  1. Mean 0, standard deviation 1, value of interest −2.
  2. The distribution is normal, so use NORM.DIST.
  3. P(X < −2).
  4. This is already a left-hand area, so no rewriting is needed.
  5. =NORM.DIST(-2,0,1,TRUE) = 0.02275.

Comment: a value picked at random from this distribution has about a 2.3% chance of being below −2.

2. Estimating intervals

Useful from Tutorial 3 onwards.

  1. Identify the information in the question. Confidence level, distribution, sample size. If no confidence level is given, choose one and state your choice.
  2. Identify what is missing but can be calculated. You can usually calculate the sample mean and standard deviation from the data.
  3. Identify the case from the table below.
  4. Calculate the interval. Use the correct spread value. This is almost always the standard error, not the standard deviation.
  5. Comment on the result.
The most common mistake A confidence interval measures how precisely you have located the mean. It does not measure how spread out the data is. The spread value is σ/√n or S/√n. Using the standard deviation alone gives an interval √n times too wide.
Why Excel calls it standard_dev

The third argument of NORM.INV is labelled standard_dev. Passing it a standard error looks wrong, but it is correct.

The argument needs the standard deviation of the distribution you are describing. For a confidence interval, that distribution is not your data. It is the distribution of sample means, and its standard deviation is the standard error. A standard error is a standard deviation, measured on a different thing.

Which case applies?

Two questions decide the case:

  • Do you know the population standard deviation? If yes, use σ. If no, estimate it from the sample and use S.
  • Can you use the normal distribution? You can if the population is normal, or if the sample is large enough for the central limit theorem. If neither is true, use t.

Worked example

A study of driving speed outside a school sampled 100 vehicles. The average speed was 25 mph with a standard deviation of 2 mph. Estimate a 95% confidence interval for the population mean.

  1. n = 100, mean 25, standard deviation 2. 95% confidence, so α = 0.05 and the tails are at 0.025 and 0.975.
  2. Nothing else needs calculating.
  3. The question does not say the population is normal, and the population standard deviation is unknown. But n = 100 is large, so this is Case 4, using the inverse normal.
  4. Standard error = 2 ÷ √100 = 0.2.
    =NORM.INV(0.025, 25, 0.2) = 24.61
    =NORM.INV(0.975, 25, 0.2) = 25.39

Comment: with 95% confidence, the mean speed of vehicles passing this site is between 24.61 and 25.39 mph.

Check that you used the standard error If you get 25 ± 3.92 mph, you have used the standard deviation, 2, instead of the standard error, 0.2. That answers a different question. It gives the range covering individual vehicles, not the precision of the mean, and it is √n = 10 times too wide.

3. Hypothesis testing

Useful from Tutorial 4 onwards.

  1. State the null and alternative hypothesis. H₀ always states that nothing has changed. Decide now whether the test is one-tailed or two-tailed. Use two-tailed to detect a difference in any direction. Use one-tailed when the question names a direction.
  2. Identify the important information. Sample sizes, means and standard deviations. Put them in a table.
  3. Choose a significance level. If none is given, state the one you use. α = 0.05 gives 95% confidence.
  4. Choose and calculate a test statistic. The table at the end of this page lists the tests.
  5. Calculate the critical value and the p-value. Calculate both. They always agree. If they do not, you have made an arithmetic error.
  6. Interpret your results. Use plain language. Never claim to have proved H₀.
Choose the direction first Choosing a one-tailed test after you see the result creates false significance. Decide the number of tails when you state the hypotheses.
Excel has no single function for this T.TEST and the Analysis ToolPak both need ranges of raw data. When a question gives you only n, the mean and the standard deviation, you must build the test from separate formulas. The Hypothesis Test Workbench does this for you.
Worked example

Leeds council surveyed bus lateness in Leeds and Manchester. 64 buses in Leeds averaged 144 seconds late; 49 in Manchester averaged 121 seconds. The standard deviation was 49 seconds in both. Is the difference significant at 95% confidence?

  1. H₀: μ_L = μ_M. H₁: μ_L ≠ μ_M. Two-tailed, because the question gives no direction.
  2. n_L = 64, n_M = 49, means 144 and 121, s = 49 for both.
  3. 95% confidence, so α = 0.05, split as 0.025 per tail.
  4. Two independent groups with an unknown population standard deviation, so use a two-sample t-test.
    t = (144 − 121) ÷ (49 × √(1/64 + 1/49)) = 23 ÷ 9.30 = 2.473
    df = 64 + 49 − 2 = 111
  5. =T.INV.2T(0.05, 111) = 1.98
  6. 2.473 > 1.98, so reject H₀.

Comment: there is evidence that bus lateness differs between the two cities. This does not explain why. It does not show that one city runs its buses better.

Which test do I need?

Two categorical variables Chi-squared Independent observations, every expected value ≥ 5

The central limit theorem makes several of these tests possible. For a large enough sample from almost any population, the sample means follow an approximately normal distribution. This is why a large n can replace the requirement for a normal population.
